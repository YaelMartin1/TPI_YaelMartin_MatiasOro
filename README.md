# Sistema de Gestión de Países

Trabajo Práctico Integrador de Programación - UTN

Aplicación desarrollada en Python que permite gestionar información de países almacenada en un archivo CSV. El sistema incluye funcionalidades de búsqueda, actualización, filtrado, ordenamiento y generación de estadísticas.

## Funcionalidades

- Carga de datos desde CSV
- Agregar países
- Actualizar información
- Buscar países por nombre
- Filtrar por continente
- Filtrar por población
- Filtrar por superficie
- Ordenar por nombre, población y superficie
- Generar estadísticas

## Tecnologías utilizadas

- Python 3
- Módulo csv
- Listas
- Diccionarios
- Funciones
- Estructuras condicionales y repetitivas
